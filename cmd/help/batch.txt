Usage: hera-agent-unity batch [--file <path.json>] [--dry-run] [--atomic]

Execute multiple commands in a single HTTP request to Unity. The whole
batch round-trips together so the response stays atomic and ordered.

Design constraint: batch is for simple sequential execution only. For
conditional branching, data passing between commands, or complex
workflows, use individual CLI calls from a shell script or AI agent.

JSON format:
  {
    "commands": [
      {"command": "manage_editor", "params": {"action": "play"}},
      {"command": "exec",          "params": {"code": "return ..."}}
    ],
    "options": { "fail_fast": true, "atomic": false }
  }

Options:
  --file <path>    Path to the JSON batch file. If omitted, reads stdin.
  --dry-run        Print the plan without executing it.
  --atomic         Force atomic mode (same as "options": {"atomic": true}).

fail_fast:
  true   Stop on first failure; return results up to that point.
  false  Execute every command regardless of individual failures.

atomic:
  Atomic accepts only non-destructive, Undo-covered scene edits; other work
  is rejected before execution, including destructive delete/remove actions.
  Only actions declared reversible, non-destructive, and unable to reload
  the domain are eligible. If any item is ineligible or unknown, the whole
  batch is rejected before execution with ATOMIC_UNSUPPORTED_ITEM and
  data.rejects entries (zero-based index, tool, action, reason). This check
  precedes approval; approval cannot make an ineligible batch atomic.
  Eligible batches use one editor Undo group, reverted if any item fails.
  Undo covers the declared Editor edits, not arbitrary script callbacks or
  external side effects. Reads without a reversible declaration, exec,
  asset/file writes, screenshots, and unreviewed actions are not eligible.
  --dry-run only prints the plan; it does not validate atomic eligibility.

Examples:
  hera-agent-unity batch --file ./play_and_test.json
  echo '{"commands":[{"command":"refresh_unity","params":{"compile":"request"}}]}' \
    | hera-agent-unity batch
  hera-agent-unity batch --file ./plan.json --dry-run
  hera-agent-unity batch --file ./scene_edits.json --atomic
