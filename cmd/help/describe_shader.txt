Usage: hera-agent-unity describe_shader [name] [options]

Inspect a shader's properties (name, type, display label, range) or search shader names. Use this before manage_material to learn which properties a shader exposes (e.g. _BaseColor, _Metallic) and their types. Pass a shader name to describe it; pass --list to search names instead.

Options:
  --name <value>
    Shader name to describe (e.g. 'Universal Render Pipeline/Lit', 'Standard'). Omit and pass --list to search names instead.
  --list <value>
    List mode: search shader names instead of describing one. Combine with --filter.
  --filter <value>
    List mode: case-insensitive substring filter on the shader name.
  --limit <value>
    Max items returned. get: properties (default 60). list: shaders (default 50). Over the limit truncates with a note.
  --include_builtin <value>
    List mode: include built-in shaders, not just project assets. Default true.

Examples:
  hera-agent-unity describe_shader "Universal Render Pipeline/Lit"
  hera-agent-unity describe_shader Standard --limit 80
  hera-agent-unity describe_shader --list --filter URP
  hera-agent-unity describe_shader --list --include_builtin false
