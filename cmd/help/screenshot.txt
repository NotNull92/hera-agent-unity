Usage: hera-agent-unity screenshot [options]

Capture a screenshot of the Unity editor, an isolated GameObject, or bounded
identity-first metadata for active uGUI Selectables and visible 3D colliders.

Options:
  --view <mode>      scene (default), game
  --width <N>        Image width in pixels (default: 1920)
  --height <N>       Image height in pixels (default: 1080)
  --camera <name>    Render one named scene camera instead of what the Game
                     view shows. Game view only; not combinable with --isolated
                     or overlay. The capture renders through a temporary copy of
                     that camera, so a scriptable render pipeline keeps driving
                     the original. The response names the camera that rendered.
  --max_resolution <N>  Cap the longest output edge, preserving aspect ratio.
                     Applied after --width and --height, so 1920x1080 with
                     --max_resolution 512 writes 512x288.
  --output_path <path>  Output path, absolute or relative to project root
                        (default: unique PNG under Screenshots/)
  --overwrite        Approval-gated replacement of an existing PNG under the
                     project or system temp directory. Existing external files
                     are never overwritten.
  --isolated         Render only one GameObject through a temporary camera
  --target <path>    Hierarchy path for isolated capture (same as --path)
  --path <path>      Hierarchy path for isolated capture
  --instance_id <N>  InstanceID for isolated capture
  --angles <list>    Comma-separated: iso, front, back, left, right, top, bottom
                     (default: iso). Multiple angles are saved as one contact sheet.
  --background <c>   #RRGGBB, #RRGGBBAA, or transparent (default: #2B2B2BFF)
  --padding <N>      Camera padding fraction for isolated capture (default: 0.15)
  --annotate_ui      Add bounded uGUI identity, interaction, blocking, and
                     coordinate metadata to a Game View screenshot
  --annotations_only Return the same UI metadata without rendering or writing PNG pixels
  --max_annotations <N>  Maximum UI elements returned, 1..100 (default: 32)
  --annotate_physics Add bounded 3D collider identity and coordinates sampled
                     through Camera.main
  --physics_only     Return the same 3D physics evidence without PNG work
  --physics_grid_size <N> Square grid density, 1..16 (default: 9; at most 256 rays)
  --max_physics_hits <N> Maximum clustered colliders, 1..100 (default: 32)
  --physics_layer_mask <N> Signed 32-bit physics mask intersected with camera culling
  --physics_max_distance <N> Positive ray distance, at most 100000 (default: camera far clip)
  --physics_query_triggers <mode> use_global, ignore, or collide (default: use_global)
  --editor_ui_only Return bounded UI Toolkit metadata for one loaded
                   EditorWindow without rendering or writing a PNG
  --editor_window <name> Exact window type, full type name, or title
  --editor_selector <selector> Optional exact #name or VisualElement type
  --max_editor_elements <N> Maximum returned elements, 1..500 (default: 100)

UI annotations require an active EventSystem and Game View coordinates. Input
coordinates use bottom-left origin with Y up; image coordinates use top-left
origin with Y down. Physics evidence requires an active Camera tagged
MainCamera, samples only the nearest visible 3D Collider per grid point, and
clusters results by collider. Metadata-only modes reject PNG output/overwrite
options. Physics2D colliders are not included.

Examples:
  hera-agent-unity screenshot
  hera-agent-unity screenshot --view game
  hera-agent-unity screenshot --view game --annotate_ui --max_annotations 50
  hera-agent-unity screenshot --annotations_only
  hera-agent-unity screenshot --physics_only --physics_grid_size 9
  hera-agent-unity screenshot --view game --annotate_physics --physics_layer_mask -1
  hera-agent-unity screenshot --editor_ui_only --editor_window InspectorWindow --max_editor_elements 50
  hera-agent-unity screenshot --view scene --width 3840 --height 2160
  hera-agent-unity screenshot --output_path captures/my_scene.png
  hera-agent-unity screenshot --isolated --target /Player --output_path captures/player.png
  hera-agent-unity screenshot --isolated --target /Player --angles front,right,top --background transparent
