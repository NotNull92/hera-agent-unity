hera-agent-unity mcp — run the experimental stdio MCP server

Usage:
  HERA_MCP_ENABLED=1 hera-agent-unity mcp --transport stdio --profile core
  HERA_MCP_ENABLED=1 hera-agent-unity mcp --exposure compact
  HERA_MCP_ENABLED=1 hera-agent-unity mcp --exposure full
  HERA_MCP_ENABLED=1 hera-agent-unity mcp --profile advanced --allow-arbitrary-code

Options:
  --transport stdio   Use newline-delimited MCP over stdin/stdout. No other
                      transport is accepted.
  --exposure <mode>   Select compact (default), profile, or full exposure.
  --profile <name>    Select core, scene, assets, ui, diagnostics, testing,
                      custom, full, or advanced.
  --allow-arbitrary-code
                      Required to start the advanced profile. Each arbitrary
                      operation still requires policy approval.
  --mrtr              Enable negotiated MCP multi-round-trip approval when the
                      client advertises Form elicitation support. Also available
                      as HERA_MCP_MRTR=1. Disabled by default.

HERA_MCP_MAX_INLINE_BYTES sets the positive model-facing result limit (default
32768). Larger results are returned as integrity-checked MCP resource handles;
credential-like and arbitrary-code results are withheld instead of stored.

Compact exposure registers only tool_search, tool_describe, and tool_call.
Search returns action names without schemas; describe returns a compact action
overview until a specific action is requested. Profile exposure registers
strict native tools from the selected catalog profile. Full exposure
registers every strict tool allowed by normal policy and excludes arbitrary
code. Approval-required operations use Connector-signed, short-lived,
single-use tokens. With --mrtr and client Form elicitation support, the MCP
session asks and resumes automatically. Otherwise the tool returns
APPROVAL_REQUIRED metadata; repeat the same call with the token in MCP request
metadata key hera/approval_token. Approval never silently downgrades.

The command is disabled by default. stdout is reserved exclusively for MCP
protocol frames; diagnostics are written to stderr. The existing CLI remains
the production default.
