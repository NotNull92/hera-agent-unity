Chapter I · The Realm

월드맵

Unity로 보내는 일반 요청이 1번부터 6번까지 처리되는 순서예요. status·task처럼 CLI 안에서 끝나는 명령이나, 오류·승인 대기로 멈춘 요청은 실행까지 가지 않을 수 있어요. 번호나 지역을 누르면 그 단계가 하는 일이 펼쳐져요.

Chapter II · Quest Journal

퀘스트 진행

명령 한 턴을 직접 진행해 보세요. 왼쪽에서 퀘스트를 고르면 도중에 사고가 났을 때 Hera가 어떻게 대응하는지 전투 기록으로 보여 줘요.

    Chapter III · Skill Trees

    스킬 트리

    도구 34종과 CLI 명령을 여덟 직업의 스킬 트리로 나눴어요. 직업을 고르고 스킬 칸을 누르면, 그 스킬이 무엇을 하고 왜 필요한지 설명이 나와요. 화살표는 먼저 익히면 좋은 스킬이에요.

    Chapter IV · Bestiary

    위험 지대

    실제 근거가 있는 위험만 몬스터로 기록했어요. 위협 등급으로 걸러 볼 수 있어요.

    Chapter V · Trials of the Sage

    그릴링

    중요한 결정을 내리기 전에 답해 봐야 할 질문이에요. 봉인을 풀면 세부 질문이 나와요. 결정이 나면 VIII 법전으로 옮기고 여기서는 지워요.

    Chapter VI · The Forge

    조합 공방

    이미 가진 도구가 재료예요. 재료를 모루에 올리면 만들 수 있는 장비가 달아올라요. 대부분은 새 도구가 아니라 에이전트 스킬(레시피 문서)로 만들 수 있어 비용이 거의 들지 않아요.

    Chapter VII · The Vault

    아티팩트

    공식 Unity CLI와 비교했을 때 Hera만 가질 수 있는 유물이에요. 비교 기준은 우리가 조사한 공식 CLI 1.0.0-beta.13이에요.

    Faction

    공식 Unity CLI

    Unity가 직접 만든 범용 도구

    • Hub 기반 Editor 설치·프로젝트 관리
    • 빌드·파이프라인 중심 (com.unity.pipeline)
    • 단일 실행 파일 (바이너리 분석으로는 .NET NativeAOT와 Rust 구성 요소가 보여요. 공식 문서로 확인한 사실은 아니에요)
    • 대화상자 상태 감지(STATUS_BLOCKED_BY_DIALOG)도 있어요. 이건 Hera만의 차별점이 아니에요.
    Faction

    Hera

    AI가 에디터 안에서 일하는 도구

    • 씬·컴포넌트·UI·테스트를 AI가 직접 고치고 확인해요
    • 게임 감각 지식서(game_feel 67주제, ui_slop 48종)를 조작 도구에 연결했어요
    • 인수에 묶인 승인 서명과 작업 기록으로 AI 실수를 막아요
    • 토큰 비용을 줄이는 응답 설계(도구 묶음, 짧은 기본값)

    Sealed Relics

    새로 제작할 만한 아티팩트

    새 아티팩트는 저장소의 "외부 참고는 완전히 Hera화한 뒤에만" 원칙과 기능 추가 관문(실제 실패 근거 먼저)을 지켜야 해요. 처음엔 스킬로 시작하고, 반복해서 쓰이면 도구로 올리는 순서를 권해요.
