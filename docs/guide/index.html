    다음 기능을 만들기 전에 집요하게 따져 볼 질문이에요. 펼쳐서 하위 질문을 확인하세요.

    이미 가진 도구(재료)를 골라 보세요. 그 재료로 만들 수 있는 새 장비가 밝게 표시돼요. 대부분은 새 도구가 아니라 에이전트 스킬(레시피 문서)로 만들 수 있어 비용이 거의 들지 않아요.

    인벤토리

    눌러서 재료를 넣고 빼요

    공식 Unity CLI와 비교했을 때 Hera만 가질 수 있는 것이에요. 비교 기준은 우리가 조사한 공식 CLI 1.0.0-beta.13이에요.

    공식 Unity CLI

    Unity가 직접 만든 범용 도구
    • Hub 기반 Editor 설치·프로젝트 관리
    • 빌드·파이프라인 중심 (com.unity.pipeline)
    • 단일 실행 파일 (바이너리 분석으로는 .NET NativeAOT와 Rust 구성 요소가 보여요. 공식 문서로 확인한 사실은 아니에요)
    • 대화상자 상태 감지(STATUS_BLOCKED_BY_DIALOG)도 있어요. 이건 Hera만의 차별점이 아니에요.

    Hera

    AI가 에디터 안에서 일하는 도구
    • 씬·컴포넌트·UI·테스트를 AI가 직접 고치고 확인해요
    • 게임 감각 지식서(game_feel 67주제, ui_slop 48종)를 조작 도구에 연결했어요
    • 인수에 묶인 승인 서명과 작업 기록으로 AI 실수를 막아요
    • 토큰 비용을 줄이는 응답 설계(도구 묶음, 짧은 기본값)

    이미 가진 시그니처

    새로 넣을 만한 시그니처 후보

    새 시그니처는 저장소의 "외부 참고는 완전히 Hera화한 뒤에만" 원칙과 기능 추가 관문(실제 실패 근거 먼저)을 지켜야 해요. 처음엔 스킬로 시작하고, 반복해서 쓰이면 도구로 올리는 순서를 권해요.
