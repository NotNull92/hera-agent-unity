### Image provenance

Created with Codex's built-in image generation tool, editing the hera-agent-godot
store thumbnail as reference. Edit instruction: keep layout, palette,
typography, terminal icon, connector and background; replace only the Godot icon
with the Unity cube mark and the subtitle with "AGENT UNITY". Resized to
1600×900 and saved as PNG and WebP.

The Unity mark is an image-generation reproduction, not the official logo file.
Unity and the Unity logo are trademarks of Unity Technologies; the mark marks the
connected engine and does not imply endorsement. Check the target store's
trademark rules before uploading.
