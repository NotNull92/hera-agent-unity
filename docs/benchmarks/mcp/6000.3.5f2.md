# MCP task-economics benchmark — Unity 6000.3.5f2

Date: 2026-08-01

Source baseline: `9922d68` plus the M15 benchmark worktree

Fixture: marked disposable Unity project created with `-noUpm`

## Scope

The benchmark performs the same read-only `scene info` task through five
surfaces:

| Variant | Surface |
|---|---|
| A | Legacy CLI (`scene info`) |
| B | Typed CLI (`call scene`) |
| C | MCP Profile |
| D | MCP Compact |
| E | MCP Full |

The harness warms each surface before recording. The table therefore measures
steady-state task execution, not first-ever catalog population. Every recorded
task uses a fresh host process and exactly one host tool call.

## Reproduction

Build the exact worktree, create an empty fixture, launch that fixture, then run
the benchmark:

```powershell
go build -o .omo/evidence/m15/hera-agent-unity.exe .
go build -o .omo/evidence/m15/benchmark-mcp.exe ./tools/benchmark-mcp

$suffix = [guid]::NewGuid().ToString("N")
$fixture = Join-Path $env:TEMP "hera-m15-fixture-$suffix"
$runID = "m15_$suffix"
$output = ".omo/evidence/m15/events-$suffix.jsonl"
.omo/evidence/m15/benchmark-mcp.exe prepare `
  --unity "$env:UNITY_HUB_EDITOR\Editor\Unity.exe" `
  --out $fixture `
  --connector AgentConnector

$editor = Start-Process `
  -FilePath "$env:UNITY_HUB_EDITOR\Editor\Unity.exe" `
  -ArgumentList @("-batchmode", "-noUpm", "-projectPath", $fixture,
    "-logFile", "$fixture\unity-editor.log") `
  -WindowStyle Hidden -PassThru

try {
  $ready = $false
  for ($attempt = 0; $attempt -lt 60; $attempt++) {
    .omo/evidence/m15/hera-agent-unity.exe --project $fixture status *> $null
    if ($LASTEXITCODE -eq 0) { $ready = $true; break }
    Start-Sleep -Seconds 2
  }
  if (-not $ready) { throw "Disposable Unity fixture did not become ready" }

  .omo/evidence/m15/benchmark-mcp.exe run `
    --hera .omo/evidence/m15/hera-agent-unity.exe `
    --project $fixture --output $output --run-id $runID
  .omo/evidence/m15/benchmark-mcp.exe summarize --input $output
  .omo/evidence/m15/hera-agent-unity.exe `
    --project $fixture console --type error --lines 20
} finally {
  if (-not $editor.HasExited) {
    Stop-Process -Id $editor.Id
    $editor.WaitForExit()
  }
}
```

`%UNITY_HUB_EDITOR%` denotes a single Unity version directory beneath the
default Windows Hub root `%ProgramFiles%\Unity\Hub\Editor`; callers may choose
another Hub root explicitly. Each invocation uses a unique fixture and output
path, and stops only the exact disposable Editor process it started. The run
command refuses projects without the disposable marker and copied Connector
dependencies.

The fixture does not resolve packages. It copies the Connector Editor sources,
excluding its test suite, plus the Newtonsoft and uGUI dependencies bundled
with the selected Unity Editor. The production project is not opened or
mutated by fixture preparation.

## Accounting limits

- This is a scripted transport baseline. It makes no model calls, so model
  calls and raw, cached, and billed model tokens are factually zero;
  `model_call_id` is `not_applicable`.
- Tool-result tokens use the deterministic estimate
  `ceil(serialized UTF-8 bytes / 4)`. They are not provider tokenizer or billing
  measurements. The JSONL records this method in `token_accounting`.
- MCP result counts include the SDK result envelope. They exclude initial tool
  definitions, outer host framing, and any model context policy.
- Each variant has one measured task. Success counts and p50/p95 describe this
  smoke run only and are not statistical model-accuracy claims.
- The task is read-only. This run does not exercise approval, mutation,
  duplicate-side-effect, or reload-recovery failure scenarios.
- Telemetry schema v2 records the actual OS process ID, MCP `tools/call`
  JSON-RPC ID, and Connector operation ID observed at their boundaries. The
  benchmark host generates its own call ID at that boundary. The Connector
  does not expose a distinct Unity HTTP request ID, so `unity_request_id` is
  truthfully `not_available`; `id_accounting` records that provenance.

These results validate the M15 harness and fixture reproducibility. They do not
promote MCP to the production default or satisfy the later M17 default-decision
gate by themselves.
